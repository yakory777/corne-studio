Статус Claude нет данных

Пока Claude Code работает, подсветка снизу плавно светится синим, когда ждёт ответа — мигает оранжевым, закончил — короткая зелёная вспышка. Подключение — одна настройка Claude Code, см. README → «Статус Claude».

Подсказки горячих клавиш Windows

Зажмите Ctrl, Win, Alt или Shift — на клавиатуре загорятся клавиши, у которых есть действие, а здесь появится список. Набор выбирается по активной программе (вкладка «Профили»).

Файл не открыт

Клик по клавише — редактировать привязку (&kp A, &mo 1, &trans, &bt BT_SEL 0…). После сохранения закоммитьте файл в репозиторий и прошейте новую сборку на вкладке «Прошивка». При подключённой клавиатуре активный слой и нажатия видны прямо здесь.

Выберите игру

Поймай огонёк — 30 секунд жмите загоревшуюся клавишу. Повтори — запомните последовательность и повторите, каждый раз на одну длиннее. Реакция — дождитесь зелёного и жмите любую клавишу, 5 попыток.

Поставьте на любую клавишу F13–F24 (вкладка «Слои» → палитра «Сниппеты») — при нажатии приложение вставит текст в активную программу. \n — перенос строки. Работает, пока Corne Studio запущена.
