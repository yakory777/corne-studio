# Corne Studio

Настройка, прошивка и отладка беспроводной клавиатуры **Corne v3** (nice!nano v2, ZMK) из одного приложения.

| Вкладка | Что умеет |
|---|---|
| **Обзор** | заряд, профиль Bluetooth, активный слой, живая схема нажатий |
| **Слои** | все слои `corne.keymap`, выбор клавиш из палитры (буквы, символы, медиа, слои, Bluetooth, подсветка) с модификаторами |
| **Подсветка** | свои эффекты в реальном времени (радуга, вихрь, круги от нажатий, огонь, цвет слоя, свой код на JS), сохранение режимов; управление встроенной подсветкой ZMK на обе половины |
| **Экран** | конструктор: страницы с ротацией и переходами, рисование пикселями, GIF, графики, кольца, аналоговые и электронные часы, реакции на события, заставка, ночной режим, любой текст и кириллица, часы, погода, CPU, статус Claude, иконки, полосы, картинки с дизерингом, анимации (звёзды, матрица, эквалайзер, «Жизнь»…), бегущая строка, яркость |
| **Статистика** | скорость печати, нажатия за день и неделю, тепловая карта, график батареи с прогнозом |
| **Прошивка** | «Собрать и прошить» в одну кнопку (git push → сборка → прошивка), причина ошибки сборки, история и откат, смена главной половины |
| **Дебаг** | проверка всех 42 клавиш и дребезга контактов, бегущий тест светодиодов, тест экрана, консоль протокола |

| **Профили** | подсветка + экран + горячие клавиши одним кликом; автопереключение по активной программе (КОМПАС, VS Code…) |
| **Игры** | «Поймай огонёк», «Повтори», «Реакция» на подсветке + 14 достижений |
| **Инструменты** | сниппеты текста на F13–F24, Pomodoro, таймер выступления, погода, калибровка цвета, резервная копия |
| **Тренажёр** | слепая печать: следующая клавиша горит на клавиатуре, ошибка вспыхивает красным; русский и английский |

Ещё: подсказки горячих клавиш (зажал Ctrl — горят клавиши с действиями), статус Claude на подсветке,
эквалайзер от звука компьютера, питомец-тамагочи на OLED, шпаргалка слоёв в PDF, значок в трее, автозапуск с Windows. План — в [ROADMAP.md](ROADMAP.md).

## Как это устроено

```
corne-studio/
├── app/                 десктоп-приложение (Electron, Windows)
├── firmware/            модуль ZMK: COM-порт по USB + протокол (PROTOCOL.md)
├── zephyr/module.yml    чтобы ZMK видел модуль
├── config/              конфиг клавиатуры: corne.keymap, corne.conf, west.yml
├── build.yaml           что собирать (левая — с модулем)
└── .github/workflows/   сборка прошивки в GitHub Actions
```

Приложение общается с **главной** (по умолчанию левой) половиной через виртуальный COM-порт, который добавляет модуль `firmware/`.
Вторая половина связана с главной по Bluetooth, поэтому её клавиши видны в приложении, а встроенная подсветка ZMK
синхронизируется на обе половины.

## Быстрый старт

### 1. Репозиторий и прошивка

1. Создайте на GitHub **публичный** репозиторий `corne-studio` и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится сама. Через 3–5 минут появится артефакт `firmware`
   с файлами `corne_left…`, `corne_right…`, `settings_reset…`.
3. Прошейте обе половины как обычно (дважды reset → скопировать `.uf2`). Дальше прошивать можно из приложения.

> Свой `corne.keymap` держите в `config/` этого репозитория. Если хотите оставить старый репозиторий
> `zmk-config` — см. раздел «Подключить модуль к другому zmk-config» ниже.

### 2. Приложение

Нужен [Node.js](https://nodejs.org) LTS.

```bat
cd app
npm install
npm start
```

Или просто запустите `app\start.bat`. Собрать один `.exe` без установки: `npm run dist` → папка `app\dist`.

Подключите главную половину по USB — приложение подключится само (или кнопка «Подключить»).

### 3. Сборка и прошивка в одну кнопку

Нужен [Git для Windows](https://git-scm.com) и токен GitHub (ниже). На вкладке «Прошивка» укажите
**папку репозитория** — приложение само откроет `config/corne.keymap` в редакторе слоёв. Дальше: правите слои →
**⚡ Собрать и прошить**.

### 4. Токен GitHub

GitHub отдаёт артефакты сборок только с токеном. Создайте его: *Settings → Developer settings →
Personal access tokens → Fine-grained*, доступ только к этому репозиторию, права **Actions: Read**.
Вставьте во вкладке «Прошивка» → «Сохранить» (хранится зашифрованным средствами Windows).
Без токена можно выбрать скачанный вручную `.zip`/`.uf2`.

## Какая половина главная

Главная половина подключается к компьютеру (USB и Bluetooth) и к приложению. Сборка делает два комплекта:

| Файл | Главная — левая | Главная — правая |
|---|---|---|
| левая половина | `main-left_corne_left.uf2` | `main-right_corne_left.uf2` |
| правая половина | `main-left_corne_right.uf2` | `main-right_corne_right.uf2` |

Сменить главную: вкладка «Прошивка» → **Сменить главную…** — мастер сбросит настройки обеих половин
и прошьёт нужный комплект. После этого в Windows удалите старое устройство «Corne» в Bluetooth и подключите заново.

## Статус Claude на клавиатуре

Corne Studio слушает `http://127.0.0.1:47800`. Добавьте в настройки Claude Code (`%USERPROFILE%\.claude\settings.json`):

```json
{
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "curl -s \"http://127.0.0.1:47800/claude?state=working\"" }] }],
    "Notification":     [{ "hooks": [{ "type": "command", "command": "curl -s \"http://127.0.0.1:47800/claude?state=waiting\"" }] }],
    "Stop":             [{ "hooks": [{ "type": "command", "command": "curl -s \"http://127.0.0.1:47800/claude?state=done\"" }] }]
  }
}
```

Подсветка снизу: синее дыхание — думает, оранжевое мигание — ждёт ответа, зелёная вспышка — готово.
На экране — режим «Статус Claude». Тот же адрес может кормить и другие устройства.

### Уведомления от чего угодно

`curl "http://127.0.0.1:47800/notify?color=00ff00&ms=2000&text=Готово"` — клавиатура мигнёт цветом.
Подходит для скриптов, ботов, планировщика задач.

## Клавиши режима прошивки

В `config/corne.keymap` добавлены:
- **Raise + левый Shift** — левая половина в режим прошивки;
- **Lower + Esc** — правая половина в режим прошивки.

Приложение переводит левую в режим прошивки само, по USB.

## Подключить модуль к другому zmk-config

В `config/west.yml` того репозитория:

```yaml
manifest:
  remotes:
    - name: zmkfirmware
      url-base: https://github.com/zmkfirmware
    - name: yakory777
      url-base: https://github.com/yakory777
  projects:
    - name: zmk
      remote: zmkfirmware
      revision: v0.3
      import: app/west.yml
    - name: corne-studio
      remote: yakory777
      revision: main
  self:
    path: config
```

И в `build.yaml` у левой половины добавьте `snippet: corne-tool`.

## Ограничения версии 0.1

- **Свои эффекты подсветки** приложение рисует само и шлёт кадрами — работают на **главной** половине,
  пока приложение открыто. Вторая в это время показывает встроенный эффект ZMK.
  Пересылка кадров на правую требует доработки split-транспорта ZMK — следующий этап.
- **Слои** редактируются в файле; изменения попадают в клавиатуру после сборки и прошивки.
  Для правки «на лету» без перепрошивки есть ZMK Studio — его можно включить отдельно.
- Экран: только латиница (шрифт ZMK), кириллица транслитерируется. В простое ZMK гасит экран.
